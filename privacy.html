プライバシーポリシー

最終更新日：2026年11月4日

yuzuru-news（以下「本ツール」）は、個人Vtuber「柚比ゆずる」のチャンネル運営者本人が、自分のYouTubeチャンネルの活動をまとめるためだけに使うツールです。

1. 取得する情報

本ツールは、Googleアカウントでの許可にもとづき、YouTube Analytics API（読み取り専用：yt-analytics.readonly）を通じて、運営者本人のチャンネルの統計情報（視聴回数、総再生時間、高評価数、チャンネル登録者の増減など）を取得します。あわせて、YouTube Data API を通じて、チャンネルの公開情報（動画・配信のタイトル、公開日時など）を取得します。

2. 利用目的

取得した情報は、1週間の活動をまとめた「週刊・柚比ゆずるニュース」を作成し、運営者が管理するDiscordサーバーに投稿するためだけに利用します。

3. 第三者への提供

取得した情報を、販売したり、広告目的で第三者に提供したりすることはありません。ニュースの文章を作成する過程で、AIアシスタント（Anthropic社のClaude）が情報を処理します。

4. 保存と削除

本ツールは、ニュース作成のために一時的に情報を処理するのみで、取得したデータを独自に蓄積しません。許可は、Googleアカウントの「サードパーティ製のアプリとサービス」から、いつでも取り消すことができます。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、限定的使用の要件を含む「Google API サービスのユーザーデータに関するポリシー」に準拠します。
